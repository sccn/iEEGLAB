1. Install

  1. iEEGLAB from github.com/sccn/iEEGLAB (Code > Download ZIP, about 250 MB, or git clone), into eeglab/plugins/. The version in the extension manager is older: please use GitHub.
  2. Restart EEGLAB. An iEEGLAB menu appears. Run iEEGLAB > Check installation.
    ExpectNo required item missing. MEF3 and bva-io may be listed as missing: they are only needed for raw MEF3 or BrainVision recordings, not for the tutorial.
    Command line
    eeglab
ieeglab_check_install

2. sEEG walkthrough (tutorial/seeg)

  1. File > Import data > From BIDS folder structure. Select tutorial/seeg; event type: electrical_stimulation_site.
    ExpectOne dataset: 18 channels, 2048 Hz, about 193 s, 34 events. Data: OpenNeuro ds004696, sub-02 (Ojeda Valencia et al., 2023, J Neurosci).
    Command line
    bids = fullfile(fileparts(which('eegplugin_ieeglab')), 'tutorial', 'seeg');
[~, ALLEEG] = pop_importbids(bids, 'bidsevent', 'on', 'bidschanloc', 'on', ...
    'eventtype', 'electrical_stimulation_site');
EEG = ALLEEG(1);
  2. iEEGLAB > Load electrode coordinates and events. Check that the electrodes, events and channels files point to the dataset; keep all channels and events.
    ExpectIn the command window: RA15, RB14 and RB15 have no coordinates and are marked bad (from channels.tsv); 34 events typed by stimulation site (RA2-RA3, RA3-RA4, RA4-RA5). You may see the warning ieeglab_load:bidsImportLabels: EEGLAB's BIDS import assigned some electrode labels by position, and iEEGLAB has restored them. This is expected until the EEG-BIDS fix is released.
    Command line
    EEG = ieeglab_load(EEG, struct('event_field', 'electrical_stimulation_site'));
  3. iEEGLAB > Visualize electrodes. Select both pial.L.surf.gii and pial.R.surf.gii in tutorial/seeg/derivatives/freesurfer/sub-02.
    ExpectA 3D brain with 15 contacts (RA lead and RB13), inside the surface.
    Command line
    surf = fullfile(bids, 'derivatives', 'freesurfer', 'sub-02', {'pial.L.surf.gii', 'pial.R.surf.gii'});
EEG = ieeglab_vis_elec(EEG, struct('surf_files', {surf}));
  4. iEEGLAB > Preprocess iEEG data. Blank stimulation artifact: on. High-pass: 0.5 Hz. Notch: 60 120 180. Epoch: -1000 1000 ms. Reject outlier trials: on. Remove bad channels: on. Baseline: -500 -50 ms (subtraction).
    Expect3 channels removed (15 left); 11.5 ms blanked around 34 pulses; 2 of 34 trials rejected (32 epochs: 11, 12 and 9 per site). A warning from EEGLAB about the "single-trial ERP baseline" is harmless.
    Command line
    EEG = ieeglab_preprocess(EEG, struct('apply_blank', true, ...
    'apply_highpass', true, 'highpass', 0.5, 'apply_notch', true, 'notch', [60 120 180], ...
    'apply_epoch', true, 'epoch_window', [-1000 1000], 'reject_trials', true, ...
    'remove_bad_channels', true, 'apply_baseline', true, 'baseline_period', [-500 -50]));
  5. iEEGLAB > iEEG re-referencing. Method: CARLA; other fields as they are.
    ExpectFor each site, the channels used as reference are printed: 8, 7 and 5 of 15. The stimulated pair is always left out. To try another method, first go back to the preprocessed dataset (Datasets menu): Common average gives 13 of 15 per site, ICA removes 9 of 15 components. CARLA: Huang et al., 2024, J Neurosci Methods. For each stimulation site it picks the channels whose common average carries no evoked response. ICA re-referencing: Michelmann et al., 2018, J Neurosci Methods. ICA splits the recording into components and removes those spread evenly over all contacts (the reference and other shared signals), keeping the local ones. A chi-square test decides: a component is "broad" when p > 0.2. Open question: the paper does not say how the component weights are scaled before the test. On raw weights in microvolts no component ever counts as broad, so the method would do nothing; iEEGLAB rescales each component first. With that, 9 of 15 components are removed on this single sEEG lead (1 of 18 on the ECoG grid), and moving the threshold between p > 0.05 and p > 0.5 changes this only to 10 or 8. On one lead much real brain activity reaches every contact, so the test may remove brain signal along with the reference.
    Command line
    EEG_car = pop_ieeglab_reref(EEG, 'method', 'car');   % to compare
EEG_ica = pop_ieeglab_reref(EEG, 'method', 'ica');   % to compare
EEG     = pop_ieeglab_reref(EEG, 'method', 'carla');
  6. iEEGLAB > CCEP analysis (N1, CRP, connectivity). On sEEG, use CRP (N1 off) and build the connectivity matrix.
    Expect"28 of 39 tested pairs respond"; most connected site RA3-RA4 (11 contacts). About 20 to 30 s (1000 permutations). CRP, Canonical Response Parameterization: Miller et al., 2023, PLOS Comput Biol. Response duration, shape and explained variance per site and contact; significance by permutation test.
    Command line
    EEG = ieeglab_stats_subject(EEG, struct('run_n1', false, 'run_crp', true, ...
    'run_matrix', true, 'matrix_source', 'crp'));
  7. iEEGLAB > Plot connectivity matrix, then Plot electrode values on brain (in-degree; CRP explained variance for site RA3-RA4) with the pial surfaces.
    ExpectA 3 sites x 15 contacts matrix; contact values on the brain.
    Command line
    ieeglab_plot_ccep_matrix(EEG.ieeglab.ccep_matrix);
ieeglab_topoplot(EEG, 'in_degree', 'surf_files', surf);
ieeglab_topoplot(EEG, 'crp_explained_var', 'site', 'RA3-RA4', 'surf_files', surf);
  8. iEEGLAB > Export results, to a folder of your choice.
    ExpectTSV tables (channels, CRP), a JSON record of every option used, and a MAT file.
    Command line
    ieeglab_export(EEG, 'results_seeg');

3. ECoG walkthrough (tutorial/ecog)

  1. Import tutorial/ecog as above (event type electrical_stimulation_site).
    Expect20 channels, 2048 Hz, about 173 s. Data: OpenNeuro ds004080, sub-ccepAgeUMCU02 (van Blooijs et al., 2023, Nat Neurosci).
    Command line
    bids = fullfile(fileparts(which('eegplugin_ieeglab')), 'tutorial', 'ecog');
[~, ALLEEG] = pop_importbids(bids, 'bidsevent', 'on', 'bidschanloc', 'on', ...
    'eventtype', 'electrical_stimulation_site');
EEG = ALLEEG(1);
  2. Load electrode coordinates and events.
    ExpectF07 and F08 marked bad ("electrode on top of other electrode"); 2 of 32 events dropped (no site); 30 events at FB53-FB54, FB54-FB55 and FB54-FB62.
    Command line
    EEG = ieeglab_load(EEG, struct('event_field', 'electrical_stimulation_site'));
  3. Visualize electrodes: cancel the surface selection.
    ExpectThe 18 grid contacts drawn on their own (fsaverage coordinates, no individual MRI).
    Command line
    EEG = ieeglab_vis_elec(EEG, struct('surf_files', {{}}));
  4. Preprocess as for sEEG, but notch 50 100 150.
    Expect18 channels, 30 epochs, no trial rejected.
    Command line
    EEG = ieeglab_preprocess(EEG, struct('apply_blank', true, ...
    'apply_highpass', true, 'highpass', 0.5, 'apply_notch', true, 'notch', [50 100 150], ...
    'apply_epoch', true, 'epoch_window', [-1000 1000], 'reject_trials', true, ...
    'remove_bad_channels', true, 'apply_baseline', true, 'baseline_period', [-500 -50]));
  5. iEEG re-referencing: Common average.
    Expect16 of 18 channels per site.
    Command line
    EEG = pop_ieeglab_reref(EEG, 'method', 'car');
  6. CCEP analysis: N1 on, CRP off.
    Expect"11 of 48 tested pairs respond", latencies 14 to 99 ms (median 21). One warning of a response above 1000 uV: very likely residual stimulation artifact. N1: van Blooijs et al., 2018, Hum Brain Mapp. iEEGLAB's default keeps the negative peak between 10 and 100 ms and tests it with a sign-flip permutation test across trials. The rule of erdetect (van Blooijs et al., 2023, Nat Neurosci), a negative peak 9-90 ms larger than 3.4 times the baseline SD taken as at least 50 uV, is an option: on the full recording it finds 71 of erdetect's 72 responses. Open question: on the full recording the permutation test finds all 72 of erdetect's responses plus 221 smaller ones that are consistent across trials but below erdetect's 170 uV criterion. Which should be the default on ECoG?
    Command line
    EEG = ieeglab_stats_subject(EEG, struct('run_n1', true, 'run_crp', false, ...
    'run_matrix', true, 'matrix_source', 'n1'));
  7. Plot the matrix (latency) and N1 amplitude on the grid for site FB54-FB62; export.
    Command line
    ieeglab_plot_ccep_matrix(EEG.ieeglab.ccep_matrix, 'latency_ms');
ieeglab_topoplot(EEG, 'n1_amplitude', 'site', 'FB54-FB62');
ieeglab_export(EEG, 'results_ecog');

4. What to report

  • Any step whose result differs from the "Expect" box.
  • Any error: a screenshot of the message and of the MATLAB command window.
  • Anything unclear in a dialog (labels, defaults, order of steps).
  • Your MATLAB and EEGLAB versions, and operating system.
